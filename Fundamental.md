1. Title
Online Learning & Course Selling Platform
2. Domain
Education Technology (EdTech)
3. Who is the User?
Admin – Manages the platform and users.
Instructor – Uploads and manages courses.
Student – Enrolls in courses and learns online.
4. What Problem are We Solving?
Students need a simple platform to access online courses and track their learning progress. Instructors need a secure way to upload and sell courses while preventing unauthorized access to their content.
5. Proposed Solution
The platform allows instructors to upload courses, videos, and study materials. Students can enroll in courses, access content securely, and monitor their progress through a personalized dashboard.
6. Core Entities / Database Tables
Users
Courses
Enrollments
Course_Content
Payments
Progress
Quizzes
Certificates
7. User Roles & Permissions
Admin
Manage users and courses
Monitor platform activities
Instructor
Create and update courses
View enrolled students
Student
Enroll in courses
Access learning materials
Track progress
8. Success Criteria
Students should be able to register and enroll in a course within 2 minutes. Only authorized users can access course content, and progress should be updated automatically after course completion.
9. Out of Scope
Live video classes
Mobile application
AI-based recommendations
Offline downloads
Virtual Reality learning
10. Chosen Track
Java (Spring Boot)
Security Feature (as per problem statement):
Secure login and authentication
Role-based access control
Protected course content delivery
Prevention of unauthorized course access and sharing
Secure storage of user and payment data
